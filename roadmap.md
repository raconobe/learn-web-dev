# 🗺️ Web Development Learning Roadmap

A structured breakdown of skills required to master full-stack web development.

---

## 📍 Phase 1: The Foundations

### 1. HTML5 (Structure)
- [ ] Basic Tags & Text Formatting
- [ ] Semantic HTML (`<header>`, `<nav>`, `<main>`, `<footer>`)
- [ ] Forms, Inputs, and Validations
- [ ] Accessibility Best Practices (ARIA)

### 2. CSS3 (Styling & Layout)
- [ ] The Box Model (Margin, Padding, Border, Box-sizing)
- [ ] CSS Selectors & Specificity
- [ ] Responsive Design & Media Queries
- [ ] Layout Systems: Flexbox & CSS Grid
- [ ] CSS Variables & Utility Frameworks

### 3. JavaScript (Behavior & Logic)
- [ ] Variables (`let`, `const`), Data Types, and Operators
- [ ] Functions, Scope, and Closures
- [ ] DOM Manipulation & Event Handling
- [ ] Asynchronous JS: Promises & `async/await`
- [ ] Working with APIs (`fetch` API)

---

## 📍 Phase 2: Frontend Frameworks & Tools

- [ ] Version Control (Git & GitHub)
- [ ] Modern Build Tools (Vite, npm/pnpm)
- [ ] React / Vue / Svelte Basics
- [ ] State Management

---

## 📍 Phase 3: Backend & Full Stack Development

- [ ] Node.js & Express / Fastify
- [ ] RESTful APIs & GraphQL
- [ ] Databases: Relational (PostgreSQL) & NoSQL (MongoDB)
- [ ] Authentication & Security
