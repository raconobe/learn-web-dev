# 🏗️ HTML5 Core Module

HTML (HyperText Markup Language) provides the fundamental structure for all web documents.

---

## 📚 Core Topics

1. **Document Anatomy:** `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`
2. **Semantic Tags:** Understanding `<section>`, `<article>`, `<aside>`, `<nav>`
3. **Forms & Accessibility:** Building user input forms with validation attributes (`required`, `pattern`).

---

## 💻 Code Example: Basic Boilerplate

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Semantic HTML Template</title>
</head>
<body>
    <header>
        <h1>Welcome to My Web Development Vault</h1>
    </header>
    <main>
        <p>This is a semantic HTML document structure.</p>
    </main>
    <footer>
        <p>&copy; 2026 Personal Vault</p>
    </footer>
</body>
</html>
```
